## whisperMeOff Season 1.1

**Voice-to-text transcription using local Whisper models**

### New Features
- 🎙️ **Voice Transcription** - Press a global hotkey to record, press again to stop
- 📋 **Auto-Paste** - Transcribed text is automatically typed into the active application
- ⌨️ **Global Hotkey** - Works from anywhere, even when minimized to system tray
- 📊 **Floating VU Meter** - Visual audio level indicator during recording
- 🌐 **Translation Support** - Translate speech to English using Whisper

### System Tray
- Left-click to show/hide window
- Right-click for Settings, Show, and Exit options

### Settings
- **Whisper Tab**: Download and select model size (tiny/base/small/medium)
- **Hotkey Tab**: Configure global hotkey (default: Ctrl+Shift+R)
- **Audio Tab**: Select microphone device

### First Release
This is the initial release of whisperMeOff - a lightweight voice transcription app that runs Whisper locally on your machine.
